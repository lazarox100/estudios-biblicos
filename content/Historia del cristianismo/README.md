# Vault: Historia del Cristianismo

## Cómo usarlo en Obsidian

1. Descomprime la carpeta.
2. Abre Obsidian.
3. Selecciona **Abrir carpeta como bóveda**.
4. Escoge la carpeta `Historia_del_Cristianismo_Obsidian`.
5. Abre `00 - Inicio.md`.

La estructura está preparada para crecer progresivamente mediante enlaces internos de Obsidian.

### Convención
- `00–07`: desarrollo cronológico.
- `90`: expedientes doctrinales.
- `91`: personajes.
- `92`: fuentes primarias.
- `93`: concilios y credos.
- `94`: tradiciones cristianas.
- `95`: bibliografía.
- `99`: plantillas.

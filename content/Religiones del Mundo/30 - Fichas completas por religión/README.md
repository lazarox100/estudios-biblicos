# README

Esta carpeta contiene 129 fichas correspondientes a las tradiciones del inventario doctrinal y dos fichas panorámicas adicionales: Cristianismo e Islam.

Cada ficha usa 22 apartados: identificación, doctrina, realidad última, cosmología, antropología, problema humano, propósito, más allá, ética, prácticas, escritura, canon, tradición interpretativa, liturgia/derecho, corpus oral, autoridad, historia, ramas, fuentes primarias, fuentes externas, evaluación histórica y bibliografía.
